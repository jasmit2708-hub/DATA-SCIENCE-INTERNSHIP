# Slab 1 – Beginner Data Science Projects

This package contains four submission-ready Jupyter notebooks.

## Projects
1. Retail Sales Data Analysis & Business Insights
2. Student Performance Analysis & Prediction
3. Customer Segmentation Using RFM & K-Means
4. House Price Analysis & Prediction

## How to run
1. Install Python 3.9+.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Open each `.ipynb` file in Jupyter Notebook, JupyterLab, VS Code or Google Colab.
4. Run the cells from top to bottom.
5. Use the generated tables/plots for your final report.

## Dataset sources
- Task 1: Sample Superstore public CSV mirror.
- Task 2: UCI Student Performance dataset.
- Task 3: UCI Online Retail dataset.
- Task 4: OpenML Ames House Prices dataset.

## Important academic note
The notebooks calculate metrics and findings from the datasets at execution time. Do not invent or manually type model scores. For Task 2, the notebook deliberately reports both a full-information model (including G1/G2) and an early-support model (excluding G1/G2), because previous grades are very strongly related to the final grade.

## Expected libraries
pandas, numpy, matplotlib, seaborn, scikit-learn, openpyxl, requests
